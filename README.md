# Причинный вывод на пальцах — часть 1

Интерактивный курс в корпоративном стиле X5: 55 страниц, адаптивная мобильная версия, анимированные схемы и практика с причинным графом.

Курс находится в `index.html` и работает без внешних зависимостей. Ответы сохраняются в браузере; для очистки используйте кнопку «Сбросить ответы».

Для публикации в GitHub Pages выберите ветку `main` и папку `/ (root)` в Settings → Pages.
